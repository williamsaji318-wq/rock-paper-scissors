## Pseudocode

1.  prompt user to start the game 
2. create a conditional so that if user says start  call the function that starts the game 
3.create a function to prompt user to enter the input rock paper or scissors and store the users choice in a variable that will be returned by the function
4. create a function that randomly picks rock papers or scissors by the computer  and stores the choice and then returns it 
5. create a function that compares users choice and computers choice and picks the winner and returns it and if both have same choice returns a tie 
6. create a round function which calls all the previous functions and display the current score of players in that round in the console and returns the total score values to finalWinner  function.
7. create two variables at beginning of program to record each players score
8. create a playGame function that loops round 5 times and calls finalWinner at the end after the loop is over  
9. create a finalWinner function that displays the winner of the match after comparing scores
